2. Corregir coordenadas invertidas en el componente StoreMap
En artifacts/mercanto/src/components/shared/StoreMap.tsx o donde estén los markers, busca la línea donde se crea el marker y verifica el orden. Mapbox usa [lng, lat] — el orden es primero longitud, luego latitud — al revés de lo intuitivo:
ts// INCORRECTO — causa markers descolocados:
.setLngLat([store.lat, store.lng])

// CORRECTO — longitud primero, latitud segundo:
.setLngLat([lng, lat])
Verifica que en TODOS los lugares donde se usa setLngLat, flyTo, fitBounds y center el orden sea siempre [lng, lat].
Revisa también el fitBounds:
ts// CORRECTO:
bounds.extend([parseFloat(String(s.lng)), parseFloat(String(s.lat))]);

// INCORRECTO:
bounds.extend([parseFloat(String(s.lat)), parseFloat(String(s.lng))]);

4. Corregir que los markers no escalan con el zoom
Los markers de Mapbox GL JS son elementos HTML normales — no escalan automáticamente con el zoom del mapa como sí lo hacen los markers de Leaflet. Esto es el comportamiento esperado de Mapbox, pero visualmente se ve mal cuando haces zoom out. Para que los markers se oculten cuando el zoom es muy bajo y sean más pequeños en zoom intermedio, agrega esta lógica después de crear el mapa:
tsmap.current.on("zoom", () => {
  const currentZoom = map.current!.getZoom();
  markers.current.forEach(marker => {
    const el = marker.getElement();
    const inner = el.querySelector("div") as HTMLElement;
    if (!inner) return;
    if (currentZoom < 8) {
      el.style.display = "none";
    } else if (currentZoom < 11) {
      el.style.display = "block";
      inner.style.transform = "scale(0.6)";
      inner.style.transformOrigin = "bottom center";
    } else if (currentZoom < 13) {
      el.style.display = "block";
      inner.style.transform = "scale(0.8)";
      inner.style.transformOrigin = "bottom center";
    } else {
      el.style.display = "block";
      inner.style.transform = "scale(1)";
    }
  });
});
Esto oculta los markers cuando el zoom es menor a 8 (vista de país completo donde no tiene sentido mostrarlos), los achica en zoom intermedio y los muestra a tamaño normal cuando el usuario está cerca.
